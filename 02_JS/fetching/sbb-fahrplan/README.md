# SBB-Fahrplan
Haben Sie sich schonmal gefragt, woher die Verbindungen aus der SBB-App kommen?
Die Daten der ÖV-Verbindungen sind öffentlich verfügbar und können von jedem:r eingesehen werden.
Ziel: Zapfen Sie die Schnittstelle an und zeigen Sie die nächsten Verbindungen ab Zug in jegliche Richtung an.

# Vorgehen
1. Informieren Sie sich in der Dokumentation über die Möglichkeiten der [Schnittstelle](https://transport.opendata.ch/docs.html)
2. Fetchen Sie in JS die Daten mit der korrekten URL
3. Stellen Sie die Resultate im HTML dar.
4. (optional) Stylen Sie die Resultate nach Ihrem Geschmack.
