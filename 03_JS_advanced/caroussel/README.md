# Caroussel / Slider
Auf Website werden Inhalte oft als Caroussel / Slider dargestellt.

## Augabenstellung
Bauen Sie einen eigenen Caroussel / Slider mit min. 5 Slides (Textinhalt und/oder Bildern). Nutzen Sie dafür HTML, CSS & JS (keine Library)

[Beispiel](https://owlcarousel2.github.io/OwlCarousel2/demos/basic.html)
